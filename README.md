# AI Chatbot

This project is a simple AI Chatbot developed using Java and Spring Boot.

## Features

- Web-based chatbot interface
- Rule-based responses
- FAQ-based question answering
- Basic text processing
- User-friendly chat interface

## Technologies Used

- Java
- Spring Boot
- HTML
- CSS
- Maven

## Project

This project was developed as part of the CodeAlpha Java Programming Internship – Task 3.
